## What Changes Compared to Upstream

This fork maintains compatibility with upstream `minio/kes` while applying:
1. **Security & CodeQL Patches:** Resolution of CodeQL alerts, least-privilege GitHub Actions permissions (`#7`, `#9`, `#13`), and Go dependency CVE bumps (`#2`, `#5`).
2. **Signed Multi-Arch Releases:** Tagged as `v0.24.0-lgcorzo.N` with Minisign signatures.
3. **Agent Transparency (`[agent]`):** Commits and PRs generated by autonomous agents are prefixed with `[agent]` so automated maintenance is clearly distinguishable from manual commits.

## Release Versioning & Publishing

Releases use semantic fork tags (`v0.24.0-lgcorzo.N`) in addition to upstream's time-based tags.
To cut a release with GoReleaser:

```shell
export GITHUB_TOKEN=mytokenvalue
goreleaser --clean
```
